# Input Handling

Beginners freeze when input looks like homework. Accept anything. Never send a form back.

## The template (share only if the user asks what to give)

```
What I can do:
What I've done before (jobs, projects, anything):
Results I've got (or "none yet"):
Industries I know:
How I describe my offer now:
Links:
Country / language / price I want:
```

Fill what you can. Skip the rest.

## What's required

Only one thing: **what they can do.** A single line like "I build n8n automations" is enough to deliver the full output.

## Accepted formats

- Filled template
- Messy brain dump
- Voice note transcript
- Pasted resume or LinkedIn About section
- Upwork or Fiverr profile text
- Just a link
- A one-liner

## Reading each input

| Input | What to pull out |
|---|---|
| What I can do | The core skill. Split vague skills into concrete tasks ("AI automation" → lead routing, invoice processing, review replies). |
| Done before | Past job titles, employers, industries, projects. This is where the edge usually hides. |
| Results | Any number or outcome, including unpaid work, own pages, friends' businesses. |
| Industries | Direct inside knowledge of how a business type runs. |
| Current offer | What to move away from. Use it to spot the generic pattern. |
| Links | Fetch them. LinkedIn shows job history. Upwork shows past gigs and reviews. Portfolio shows work types. |
| Country / language | Local market access, time zone overlap, language edge (for example a Spanish speaker selling to US Hispanic-owned businesses). |
| Price | Their comfort range. Adjust to the market check in niche-selection. |

## Thin input rules

- **One line only:** pick a niche where that skill has clear, visible demand and a buyer group easy to find online. Favor local service businesses or small ecommerce, since beginners can reach them and the pain is visible.
- **Only a link:** fetch it and treat what you find as the full input.
- **No results:** that's fine. Handle it in the offer with a low-risk first deal. Never invent.
- **No industry experience:** use location, language, tool depth, or personal interests as the edge. If none exist, pick the niche with the most visible pain and easiest list building.
- **Contradictions** (for example a price far above market): use the market price and make the offer structure bridge the gap.

## Hard stop cases

If the "skill" is not a sellable service (for example "I want to make money"), still deliver: pick the most common beginner service that matches anything in their history, and build the four sections around it.
