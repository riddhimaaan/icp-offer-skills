# Anti-Generic Gate

Run every test on the draft. Any fail means rewrite that part before output.

## ICP tests

1. **List test:** Could someone build a list of these businesses today using the filters given? If a filter can't be typed into a tool or search, replace it.
2. **Size test:** Is the market narrow enough to feel specific (roughly 200 to 5,000 businesses) but wide enough to fill a few months of outreach?
3. **Buyer test:** Is the person who pays named by title?
4. **Skip test:** Are there disqualifiers? An ICP that excludes nobody is not an ICP.

## Offer tests

1. **Freelancer swap test:** Could 1,000 other beginners paste this exact offer? If yes, it's generic. Add the niche, the task, the time or scope, and the risk reversal.
2. **5 second test:** Would the buyer know what they're getting after one read?
3. **Truth test:** Does every claim in "Why trust you" come from the user's input? Remove anything that doesn't.
4. **Number test:** Is there a price or a tight range?
5. **Deliverable test:** Can the buyer picture the thing they receive?

## Trigger tests

1. **Link test:** Does each trigger connect to the offer's specific problem?
2. **Visible test:** Can it be seen from outside?
3. **Universal test:** Is any trigger a bare universal ("raised funding", "hiring")? Add the condition that ties it to the offer or cut it.
4. **Count test:** 3 to 5 triggers.

## Where to find tests

1. **Named source** for each trigger.
2. **Exact search, filter, or query** a beginner could copy.
3. **Named tool** to pull the list.
4. **Same order and count** as Triggers.

## Output tests

1. Exactly four sections: ICP, Offer, Triggers, Where to find them.
2. No intro, summary, questions, or next steps.
3. No em dashes.
4. No banned phrases (see list below).

## Banned phrases (anywhere in output)

scale, scaling, grow your business, 10x, leverage, unlock, streamline, cutting edge, game changer, revolutionize, take it to the next level, boost your revenue, done for you solutions, synergy, empower, seamless, holistic, robust, elevate, supercharge, in today's fast paced, businesses of all sizes, small and medium businesses, SMBs, decision makers, key stakeholders, value proposition, pain points

## The final check

Read the full output as the beginner. Ask: "Could I start building a list and sending messages tomorrow with only this?" If not, fix the weakest section.
