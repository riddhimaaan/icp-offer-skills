# ICP + Offer Skills

Two Claude skills for picking the right buyer for your offer.

## beginner-icp-offer-finder
Turns vague skills or a generic offer into a sharp ICP, a specific offer, buying triggers, and where to find those triggers.

## product-market-fit
Runs a PMF analysis for a product and audience. Covers ICP, offer validation, buyer fit and a PMF score.

## How to use
Zip a skill folder and upload it in Claude under Settings > Capabilities > Skills.
